DAEV GUITARS - неофициальная концепция сайта.

Использованы иллюстративные изображения с Unsplash, не являющиеся фотографиями работ мастерской. Услуги, цены и контакты сверены с публичным сайтом, перед релизом необходима перепроверка.

## Ветка wordpress-migration

- [Инструкция по установке, редактированию и переносу](wordpress/daev-guitars/README.md)
- [Исходники темы DAEV Guitars](wordpress/daev-guitars/)
- [Установочный ZIP](wordpress/daev-guitars.zip)

Статический `index.html` использует локальные стили, шрифты и изображения темы. Для просмотра ветки запустите `python3 -m http.server 8090` из корня репозитория и откройте `http://localhost:8090/`. Опубликованная демонстрация GitHub Pages берётся из `main`.
