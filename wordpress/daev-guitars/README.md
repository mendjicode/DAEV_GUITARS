# DAEV GUITARS для WordPress

Тема сохраняет оформление HTML-концепции мастерской Александра Даева. Работы и услуги редактируются в Gutenberg. Для текстов, фотографий и контактов главной используется стандартный экран WordPress «Настроить». Для работы темы достаточно WordPress 6.5+ и PHP 8.1+. Установку для заказчика лучше начинать на тестовом адресе.

## Установка

1. В панели WordPress откройте **Внешний вид → Темы → Добавить новую → Загрузить тему**. Выберите `daev-guitars.zip` и нажмите **Установить**, затем **Активировать**. Для ручной установки распакуйте каталог `daev-guitars` в `wp-content/themes/`.
2. В **Настройки → Общие** установите язык сайта **Русский** и задайте название сайта. В **Настройки → Постоянные ссылки** выберите **Название записи** и сохраните для адресов вида `/raboty/nazvanie-raboty/`.
3. Откройте главную страницу. Тема выводит её через `front-page.php`, отдельная страница для конструктора не нужна. При первой активации появятся три карточки услуг из концепции. Проверьте их описания, перечень услуг и контакты перед запуском.
4. На тестовом сайте включите **Настройки → Чтение → Попросить поисковые системы не индексировать сайт**. Если тестовая версия доступна по публичному адресу, ограничьте доступ средствами хостинга.

## Как добавить работу

1. В панели выберите **Работы → Добавить работу**. Укажите название и опишите инструмент, задачу и результат в редакторе блоков.
2. Для снимков добавьте блок **Галерея** или **Изображение**. Можно загрузить новые файлы либо выбрать их из медиатеки. Добавьте альтернативный текст к содержательным фотографиям. В панели записи отдельно укажите **Изображение записи**. Оно станет обложкой карточки.
3. Нажмите **Опубликовать**. Карточка автоматически появится в разделе «Проекты» и в архиве работ. На главной видны девять последних публикаций. Если работ больше, там появится ссылка **Все работы**. Черновики остаются в панели. При снятии записи с публикации карточка исчезает.
4. Пока нет опубликованных работ, галерея может показывать подписанные изображения из концепции. Они исчезают после первой публикации. Чтобы скрыть их уже на тестовом сайте, выключите соответствующий переключатель в **Внешний вид → Настроить → DAEV · Главная и контакты → Услуги и портфолио**.

## Как обновить услуги и цены

1. Откройте **Услуги → Все услуги** и выберите запись или нажмите **Добавить услугу**. Отредактируйте название и описание в Gutenberg. Поле **Отрывок** задаёт короткое описание карточки. Если оно пустое, тема использует начало основного текста.
2. На вкладке **Услуга** справа найдите блок **Карточка и цена**. В зависимости от версии WordPress он может находиться под редактором. Отметьте **Показывать карточку в разделе «Услуги»**, если нужна большая карточка. Задайте адрес кнопки из списка и выберите настоящее **Изображение записи**. В трёх стартовых карточках подпись «Иллюстрация» автоматически исчезнет после замены обложки.
3. Введите подтверждённую стоимость в поле **Цена**, в том виде, в каком её должен увидеть посетитель. Сохраните или опубликуйте запись. В прайс попадают опубликованные услуги с заполненной ценой. Для услуги, которой нужна только строка прайса, оставьте выключенным показ карточки. Чтобы убрать стоимость с сайта, очистите поле и сохраните запись.
4. Суммы из HTML-концепции не импортируются. До заполнения прайса посетитель увидит ссылку на контакты мастерской.

## Как обновить главную и контакты

Откройте **Внешний вид → Настроить → DAEV · Главная и контакты**. Выберите нужный раздел и после проверки предпросмотра нажмите **Опубликовать**.

- **Первый экран** и **Подход и философия** содержат поля для заголовков, описаний и выбора фотографий. Строка с акцентом сохраняет другой цвет или курсив. Переносы можно задавать клавишей Enter в многострочном поле. Тема также переносит длинный текст по ширине экрана.
- **О мастерской**, **Услуги и портфолио** и **Прайс** содержат тексты главной и примечания.
- **Контакты** содержат адрес, график, телефон, Telegram и необязательную ссылку на действующий сайт. Адрес и график автоматически обновляются и в верхней полосе. Если новый сайт открывается на адресе действующего, очистите эту ссылку.
- Фотографии на первом экране и в разделе «Подход» изначально подписаны как иллюстративные. Замените их фотографиями мастерской через медиатеку. Для фонового снимка лучше выбрать широкое фото с инструментом справа. Расположение секций и стили задаются темой.

## Как перенести на хостинг

1. Подготовьте на хостинге WordPress с PHP 8.1+, MySQL или MariaDB, HTTPS и поддержкой постоянных ссылок. Сначала проверьте тему на тестовом адресе. Убедитесь, что лимиты PHP и веб-сервера позволяют загрузить ZIP и фотографии.
2. Если переносится только тема, установите ZIP по инструкции выше и заполните сайт на новом сервере. Если тестовый WordPress уже заполнен, перенесите **базу данных**, каталог `wp-content/uploads` и тему. Работы, услуги, цены и настройки главной находятся в базе. ZIP содержит файлы темы. Перед переносом сделайте резервную копию исходного и целевого сайтов.
3. Для переноса заполненного сайта следуйте процедуре хостинга, поддерживающей поля WordPress с сериализованными данными. При наличии WP-CLI после импорта базы сначала выполните проверку, подставив фактические адреса.

   ```sh
   wp search-replace 'https://staging.example.com' 'https://example.com' --all-tables-with-prefix --skip-columns=guid --dry-run
   ```

   Проверьте список замен, затем повторите команду без `--dry-run`. Проверьте значения `home` и `siteurl`, а также возможные переопределения `WP_HOME` и `WP_SITEURL` в конфигурации. Сохраните постоянные ссылки в админке и очистите кеш хостинга.
4. Проверьте главную, карточки, архив, цены, фотографии в полном размере, телефон и Telegram на новом адресе. Подтвердите данные и замените иллюстрации. После согласования запуска снимите ограничение индексации на рабочем сайте. GitHub Pages и рабочий хостинг WordPress управляются отдельно.

## Файлы и данные

Стили и скрипт из `assets/` используются и темой, и статической демоверсией из ветки миграции. Шрифты DM Sans, Manrope, Oswald и Playfair Display поставляются локально, лицензии SIL OFL лежат в `assets/fonts/`. Иллюстрации сохранены из первоначальной концепции и оптимизированы в WebP. [Unsplash](https://unsplash.com/license)

Типы записей и настройки главной зарегистрированы в теме. При смене темы данные сохраняются в базе. Чтобы снова открыть эти записи и настройки через привычные разделы, активируйте DAEV Guitars.
