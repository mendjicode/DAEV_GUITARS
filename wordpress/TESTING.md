# Отчёт о миграции DAEV GUITARS

## Результат

- Статическая версия в ветке `wordpress-migration` и WordPress-тема используют общие стили, скрипт и локальные ресурсы. Сохранены композиция главной, контрастные секции, основные шрифты и фотографии концепции. В заголовках увеличен межстрочный интервал, ослаблено отрицательное межбуквенное расстояние и уменьшены минимальные размеры на узких экранах.
- Основной текст выделяется песочным цветом. У крупных заголовков секций обычное выделение отключено через CSS. Заголовки остаются текстовыми и доступны вспомогательным технологиям. Примечание статической демоверсии размещено под кнопками первого экрана, чтобы оно не перекрывало текст при прокрутке.
- Стартовые карточки услуг перенесены из концепции. WordPress показывает цены только из опубликованных записей с заполненным полем. Иллюстративные изображения подписаны. Галерея заменяет иллюстрации опубликованными работами.
- Темой предусмотрены стандартные метки заголовка страницы, метаописания главной и отдельных записей, ссылки на работы и услуги. Фотографии темы локальные, в WebP. Для загруженных фотографий используются размеры и `srcset` из WordPress.

## Проверка в браузерах

Проверены Chromium 156 и Firefox 159 в Linux. Для статической и WordPress-версии использованы ширины **320, 375, 390, 430, 768, 1024, 1366 и 1920 px**. Дополнительно проверены 520, 521, 790, 791, 900, 901, 1100 и 1101 px около переходов сетки.

- На этих ширинах проконтролированы загрузка кириллических шрифтов, границы строк заголовков, переносы слов и отсутствие горизонтальной прокрутки.
- Визуально просмотрены три заголовка из задания на 320, 1366 и 1920 px.
- Проверены выделение мышью, ссылка перехода к содержимому, открытие меню с клавиатуры, закрытие по Escape, переход к разделу и кнопка «Наверх». При отключении JavaScript навигация остаётся доступной.
- Автоматическая проверка axe по правилам WCAG A/AA для двух версий на 320 и 1366 px завершилась без найденных нарушений. Проверка охватывает проверяемые автоматически правила.

## Проверка WordPress

Проверка выполнена в локальных контейнерах с WordPress 7.1.5, PHP 8.3.37 и MariaDB 11.4.13, с русским языком интерфейса.

- ZIP загружен и активирован через «Внешний вид → Темы». После повторной активации сохранились работы, услуги и контакты. Установленные файлы совпадают с архивом.
- Через Gutenberg опубликована работа с загруженной фотографией. Проверены появление карточки вместо иллюстраций, ссылка на отдельную страницу, архив и адаптивная разметка изображения. При двенадцати публикациях проверены девять карточек на главной, две страницы архива и отсутствие черновика на публичных страницах.
- В Gutenberg обновлены название, описание и ссылка карточки услуги. Проверены добавление цены, переход из прайса на страницу услуги и исчезновение строки после очистки цены.
- Через «Настроить» сохранены адрес, телефон, текст главной и новое фоновое изображение из медиатеки. Проверены адрес в верхней полосе, ссылка `tel:` и загрузка новой фотографии.
- Файлы PHP прошли `php -l`, скрипт прошёл `node --check`. Установочный архив содержит 40 файлов и побайтово соответствует исходникам темы.

## Перед запуском на хостинге

Подтвердить с Александром адрес, часы работы, способы связи, направления услуг и прайс. Заменить иллюстрации фотографиями мастерской. На тестовом адресе проверить HTTPS, постоянные ссылки, отправку в Telegram, звонок по ссылке на телефоне и обновление страниц после правок при включённом кешировании. Safari и физические мобильные устройства остаются к проверке.

Опубликованная GitHub Pages использует ветку `main`. Миграция подготовлена в `wordpress-migration`.
